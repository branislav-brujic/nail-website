Can I use my existing AI accounts?

Yes. Supported CLI integrations reuse existing sign-ins, as do the Claude and Codex SDK adapters. The optional Antigravity SDK uses separate API or Vertex/ADC credentials. NAIL does not include an AI service subscription.

Can agents keep working with the browser closed?

Yes. Chats and queued messages stay active while the NAIL server is running. Resuming work, approvals and limit tracking depend on the integration.

Can I run NAIL on my own server?

Yes. User roles, MFA, HTTPS and an optional bubblewrap sandbox are available. You can also use a local Ollama model for AI summaries.
